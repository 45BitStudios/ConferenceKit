## When this applies

Use this for talks on the schedule: what is on now, what is next, a topic, or saving a talk. A person giving a talk is a speaker. That is not the same question as an attendee in the directory.

## What you need

A topic, a session name, or nothing at all when they only ask what is happening. If find a session returns more than one talk, name each match with its room and start time and let them choose. Do not pick for them.

## Steps

Use find a session when they name a topic or a title. Use what's next when they ask what is on now or coming up. Say the room and the start time the tool returned. If they already saved a matching talk, say so.

Offer to favorite a session only after you have named it. Ask them to confirm before it is saved. If they cancel or say no, do not save it. Removing a saved talk happens only when they ask. This guidance does not undo a save by itself.

## Boundaries

Do not invent a session, a room, or a time. Do not export notes. Do not read attendee contact details.

A reminder and adding a talk to Calendar are ordinary actions in the app. They are not these schedule tools. If they ask for either, tell them to use the session screen in the app.

## When a tool does not run

These schedule tools are custom Siri tools. They need Siri's connection. This guidance cannot tell whether that connection is up, and it must not claim that it is. If a tool does not run, say so and point them to the Schedule and My Schedule screens in the app. Those screens still work on the device.

This skill is optional. The tools still work when the skill is not used.
