---
name: recall-notes
description: Finds what the person wrote about a topic or a session and reads those notes back.
---
Use the find session tool to resolve the talk they mean, including a topic such as Duo.
Then use the show notes tool for that session.
Quote only the note text the show notes tool returns. If there are no notes, say so.
Do not add a note unless they asked to write one. If they did, use the add note tool and leave the session unset when a session is already on screen.
