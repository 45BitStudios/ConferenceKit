---
name: find-attendee
description: Looks up a person in the conference attendee directory. Use when someone asks who is attending or asks for an attendee by name. Not for speakers on the schedule, and not for reading an email or sending a message.
---

The find attendee tool returns names and roles from the directory. Say only those fields.

The tool does not return an email, a phone number, or a social link. If the person asks for those, say they are not in this answer. Do not guess them.

If the tool does not list the person, say they are not in the directory.

This skill is optional guidance. The find attendee tool still works if the skill is not used. Do not require another tool to run first, and do not undo an earlier action.

Do not claim a message was sent. Messaging in this app stays on device until a conference service is connected.
