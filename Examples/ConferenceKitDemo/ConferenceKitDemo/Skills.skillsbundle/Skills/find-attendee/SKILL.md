# Find an attendee

Use attendee lookup. Repeat only the names and roles it returns.

It does not return email, phone, or social links. Do not invent them.

If the person is not listed, say so.

This skill does not force a tool order and does not undo a previous action. The lookup still works without the skill.

Do not say a message was delivered. The demo transport keeps messages on this device.
