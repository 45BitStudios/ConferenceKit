---
name: write-notes
description: Writes a note on a conference session. Use when someone asks to jot a line or to save a drafted note. Not for reading notes back or exporting them.
---

## When this applies

They want a new note. Add a note is a short line on the session that is on screen or live. Create a session note is a draft they want checked and then saved.

## What you need

The words they want saved, in their wording. A session, unless one is already on screen or live. If find a session returns several talks, ask which one. Do not attach the note to a guess.

## Steps

When a session is on screen or live, leave the session unset and add a note. Otherwise find a session first, then add a note.

Create a session note when they handed you a draft to check. The app asks them to confirm before that draft is saved. If they cancel, nothing is written.

An empty note is not saved. Say that it was empty and ask for the words. If no session is on screen and they did not name one, say so and ask which talk.

## Boundaries

Keep their words. Do not invent a talk or a note they did not say. Do not show existing notes or export them unless they ask. This guidance does not delete or replace an older note.

## When a tool does not run

If a note tool does not run, tell them to open the session in the app and type the note there. Notes stay on this device. This skill is optional. The note tools still work without it.
