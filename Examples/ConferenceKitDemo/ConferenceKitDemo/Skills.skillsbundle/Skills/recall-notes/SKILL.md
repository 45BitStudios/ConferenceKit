---
name: recall-notes
description: Reads back notes the person already saved for a talk. Use when they ask what they wrote. Not for writing a new note or exporting every note.
---

## When this applies

Their own notes for one session or one topic. Not another person's notes, and not the attendee directory.

## What you need

Which session. Use find a session when they name a topic, such as a product or a room theme. If several talks match, ask which one before you show the notes.

## Steps

Find a session, then show the notes for that session. If there are no notes, say so. Do not invent any.

Summarize what show the notes returned. Do not read a note aloud unless they explicitly ask you to. Do not add a note unless they ask to write one.

## When a tool does not run

Tell them to open My Notes in the app. This skill is optional. It does not delete notes, and it does not undo a note that was already saved. Notes remain on this device.
