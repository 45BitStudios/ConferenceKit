# Session Notes

To write a note, use the create session note tool. Leave the session unset when a session is on
screen or happening now; otherwise use the find session tool first and ask which talk if more than
one matches. Keep the note in the person's words.

To read notes back, use the show notes tool for the session they mean, and summarize. If there are
no notes, say so.

## Don't

- Don't read private notes aloud. Show them on screen, or summarize them, unless the person
  explicitly asks you to read a note out loud.
- Don't add a note the person didn't ask for.
- Don't export or share notes unless they asked.
